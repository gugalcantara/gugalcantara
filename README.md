### Projetos

#### Opero
**Planejamento e controle de produção**

Aplicação web que substitui a planilha de programação de fábrica. Modela a jornada real da empresa (expediente, almoço, feriados e hora extra) no cálculo de início e término de cada ordem de produção, com dois motores de agendamento e 648 testes automatizados.

`React` `Vite` `Tailwind` `Vitest`
Projeto Autoral. Código Proprietário.

<br>

#### ImovAI
**Gestão de Leads para Imobiliárias**

Plataforma SaaS em produção, em uso por imobiliárias de pequeno porte. Respondo pela camada de dados: modelagem do schema relacional, migrations versionadas, índices, views e Row Level Security.

`PostgreSQL` `Supabase`
Projeto em Equipe. Acesse em [imovai.net](https://imovai.net).

<br>

#### Reconhecimento de Letras com Rede Neural
**Classificação das 52 letras do alfabeto**

Classificador MLP treinado sobre 10.400 imagens sintéticas que o próprio projeto gera com data augmentation, dispensando dataset externo. Interface interativa com métricas, matriz de confusão e análise das confusões entre maiúsculas e minúsculas.

`Python` `scikit-learn` `Streamlit`
Projeto Acadêmico em Equipe. [Ver repositório](https://github.com/gugalcantara/reconhecimento-letras-mlp).

<br>

#### Análise de Emergia
**Cálculo e análise emergética**

Aplicação web para cálculo de emergia, com arquitetura modular e interface de apoio a estudos da área.

`TypeScript` `React`
Projeto Acadêmico em Equipe. [Ver repositório](https://github.com/gugalcantara/ts_emergia-analysis).

<br>

#### Infraestrutura de Rede Distribuída
**Simulação de rede para análise emergética**

Simulação de desempenho, segurança em camada 7 e alta disponibilidade, aplicando conceitos de redes e sistemas distribuídos.

`JavaScript`
Projeto Acadêmico em Equipe. [Ver repositório](https://github.com/gugalcantara/infraestrutura-rede-distribuida).
